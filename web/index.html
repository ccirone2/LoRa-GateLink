Apply changes RAM (radio settings take effect immediately). Save writes flash. Uploading new firmware erases saved config and key — export first. Both boards must share net_id, radio settings and key.

Link key

Every frame is authenticated with HMAC-SHA256 using a shared 128-bit key. Both boards must have the same key. The key is write-only; it can't be read back from a board.

Key set on this board—

Generate once, write it to this board, then connect the other board and write the same key. Keep a copy somewhere safe.
